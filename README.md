# FPL Analytics — Tactical Intelligence

A static, browser-based analytics dashboard for Fantasy Premier League (FPL). Presents player/team statistics and tactical insights in a single-page interface.

## Technology stack

- **Frontend:** HTML, CSS, JavaScript (single-file application, no build step).

## Running locally

Open `index.html` in a modern browser.

## Limitations

- Static frontend only; no backend or live data pipeline in this repository.
- Data is embedded or loaded client-side.
